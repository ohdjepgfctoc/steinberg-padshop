## Overview

Padshop is Steinberg's granular synthesizer, splitting samples into grains and recombining them with independent position, speed, and pitch scatter to create dense, evolving atmospheric pad textures.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Steinberg Padshop** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Grain Engine** | Up to 200 simultaneous grains per voice with scatter and randomization |
| **Sample Import** | Load custom WAV samples as granular source material |
| **Spectral Layer** | Optional second layer using spectral resynthesis for hybrid sounds |
| **Mod Matrix** | 16-slot modulation matrix with four LFOs and two envelopes |
